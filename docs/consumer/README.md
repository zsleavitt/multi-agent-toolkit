# Consumer guide — adopting MAT in your repository

This section is for teams who want **Multi-Agent Toolkit (MAT)** contracts, runtime, and skills **inside their own repo**, not only when hacking on the toolkit itself.

| Guide | What you get |
|-------|----------------|
| [Getting started](getting-started.md) | Ways to vendor MAT, first-run setup, smoke checks |
| [`ai-team.repo` profile](ai-team-repo-profile.md) | Portable identity, paths, and work-item adapters |
| [Installing skills](installing-skills.md) | Claude Code plugin and Cursor rules |
| [Example workflows](workflows.md) | Feature work, bugs, PR review |
| [Troubleshooting](troubleshooting.md) | Common failures and fixes |
| [Migration](migration.md) | Moving from other agent or CI setups |

**Specs and schemas:** deeper reference lives under [`schemas/`](../../schemas/) (for example [`schemas/ai-team-repo-profile/v1/README.md`](../../schemas/ai-team-repo-profile/v1/README.md) and [`schemas/provider-config/v1/README.md`](../../schemas/provider-config/v1/README.md)).
